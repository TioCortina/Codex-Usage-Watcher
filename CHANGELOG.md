# Changelog

## 3.1.0

- Soporte para Brave, Google Chrome y Microsoft Edge.
- Detección del navegador predeterminado compatible.
- Nuevo `CONFIGURE_BROWSER.bat`.
- Perfil dedicado independiente por navegador.
- Migración compatible con perfiles Brave de versiones anteriores.
- Instalador único actualizado para selección multinavegador.
- Documentación y guía de seguridad actualizadas.

## 3.0 Public

- Edición Windows-only.
- Instalación principal mediante `INSTALL_WINDOWS.bat`.
- Brave normal ejecutado oculto para reducir interferencia visual.
- Perfil de Brave dedicado a la lectura de Codex Usage.
- Alertas de límites de 5 horas y semanales.
- Alertas previas a reset.
- Notificaciones push mediante ntfy.
- Topic ntfy único generado en cada instalación nueva.
- `config.json` excluido del repositorio.
- Zona horaria local del sistema por defecto.
