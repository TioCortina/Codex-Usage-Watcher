# Contribuir

Los issues y pull requests son bienvenidos.

1. Crea un fork y una rama para tu cambio.
2. No incluyas `config.json`, perfiles de Brave, cookies, tokens ni archivos de estado.
3. Prueba `INSTALL_WINDOWS.bat`, la captura oculta y `STATUS_WINDOWS.bat`.
4. Describe qué cambió y cómo lo verificaste.

Este proyecto depende de texto y comportamiento de una interfaz web que puede cambiar; los cambios de parser deben incluir ejemplos anonimizados del texto que se pretende reconocer.
